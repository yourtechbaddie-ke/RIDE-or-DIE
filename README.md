# RIDE OR DIE

## Chapter 1 Production Foundation

**Working title:** *The Last Normal Day*

This repository is the production home for the Ride or Die game design, narrative, world, characters, UX, technical architecture, and eventual Unreal Engine implementation.

### Current milestone
Chapter 1 is the first 60–90 minute vertical-slice target. It demonstrates cinematic storytelling, exploration, survival, driving, contextual interaction, branching dialogue, relationships, resource management, investigation, environmental storytelling, audio horror, and the first ECHO encounter.

### Canonical ending
At 2:13 AM, the protagonist investigates an unexplained radio transmission. The radio repeats the protagonist's own voice. A brief impossible visual reveals Hollowgate as pristine and populated, with everyone staring directly at the player. Noah appears with his toy dinosaur and says: **"You."** The chapter ends on the four-note ECHO motif.
