## Milestone A — Playable shell
- Unreal project initialized
- Android target configured
- input actions
- player controller
- camera
- basic interaction
- placeholder HUD

## Milestone B — Opening sequence
- highway environment blockout
- vehicle prototype
- driving controls
- crash cinematic
- post-crash traversal

## Milestone C — Hollowgate
- settlement blockout
- lighting/time-of-day
- interactable props
- basic NPC navigation
- food/rest interaction

## Milestone D — Narrative systems
- dialogue data
- choice UI
- quest state
- relationship state
- persistent variables
- journal/evidence entries

## Milestone E — Characters
- protagonist
- Mara
- Jace
- Noah

## Milestone F — ECHO
- radio interaction
- four-note motif trigger
- authored voice event
- impossible visual state
- Noah ending sequence

## Milestone G — Persistence and polish
- save/load
- checkpoint recovery
- audio pass
- haptics
- accessibility
- performance profiles
- Android profiling
- QA regression

## Definition of done
Chapter 1 is ready for external playtest only when the full 60–90 minute flow can be completed from a clean install/save, choices persist correctly, the ending reliably triggers, and the build performs acceptably on the defined Android test matrix.
