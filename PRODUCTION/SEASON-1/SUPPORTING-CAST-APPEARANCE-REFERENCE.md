# RIDE OR DIE — SUPPORTING CAST APPEARANCE REFERENCE

## Status
**Production reference — appearance identities locked for visual development.**

## Purpose
This document establishes visually distinct, production-consistent appearances for the named supporting cast. It is the reference to use before generating character portraits, turnarounds, animation assets, wardrobe states or promotional art.

The appearance system follows Layers 101–103: appearance must communicate identity, occupation, personality, class, lived experience and changing survival conditions. Clothing is not a static costume; it evolves across the story.

## Global visual rules
- No two supporting characters should read as visually interchangeable at a glance.
- Diversity is intentional: the ensemble includes multiple racial, ethnic and cultural backgrounds rather than defaulting everyone to one look.
- Ethnicity/background is only stated where established in existing character canon; where the earlier dossier did not specify background, the visual identity below is treated as a production choice, not a claim about prior canon.
- Signature possessions are continuity anchors and should recur where appropriate.
- Distinguishing features should remain recognizable after wardrobe changes, dirt, injury, weathering or time progression.
- Before The Collapse, clothing should fit occupation, wealth, geography and ordinary life. During The Collapse, wardrobe should adapt rather than becoming a generic "survivor" costume.
- Avoid identical haircuts, facial structures, silhouettes, color stories or accessory combinations across characters.

# Visual differentiation checklist
Before generating any image from this file, verify:

- [ ] Face shape differs clearly from adjacent characters.
- [ ] Hair texture, length and styling are not duplicated without narrative reason.
- [ ] Skin tone and cultural presentation are not being flattened into a single default look.
- [ ] Body silhouette is distinguishable at full-body distance.
- [ ] Signature object is present when the scene allows it.
- [ ] Wardrobe reflects occupation and personality rather than generic genre clothing.
- [ ] Collapse-state clothing shows individual adaptation rather than identical dirt/tears.
- [ ] Character remains recognizable when wardrobe changes.
- [ ] No character accidentally inherits another character's signature visual feature.

## Canonical production rule
**Every supporting character gets a face, silhouette, hair identity, wardrobe identity and signature visual anchor that can survive a wardrobe change.**

This document is the visual reference for future supporting-character image generation unless a later canon revision explicitly supersedes an entry.
