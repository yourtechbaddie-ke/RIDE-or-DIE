# RIDE OR DIE — CHARACTER VISUAL MASTER

## Canonical status
**Production reference — visual identity master.**

**Roster lock: 51 main characters + 18 supporting characters = 69 named characters.**

This is the canonical visual index for character-image generation, portraits, turnarounds, gameplay references, cinematics and wardrobe continuity. It supersedes the deleted `CORE-51-CHARACTER-APPEARANCE-MASTER.md` as the master visual reference and deliberately separates the 51 main characters from the 18 supporting characters.

## Non-negotiable production rules
- Never invent an additional character to satisfy the 69 count.
- Never move a supporting character into the 51 without an explicit canon change.
- **Mara** is the canonical name; never use Raven.
- **Damian Bellamy** is the canonical tattoo artist; never use the retired working name Knox Bellamy for him.
- **Sterling Knox** is the private-security professional/protector and is a different person from Damian Bellamy.
- **Dr. Vera Voss is main character #51.**
- **ECHO is non-human** and must not be generated as an ordinary human character.
- The player has **no fixed canonical physical identity**. “Protagonist” is a registry placeholder only; never silently canonize a face, race, body or outfit.
- No two characters may share the same complete combination of face structure, hair, body silhouette, wardrobe language and recognition anchor.
- Characters must not all be Black, white, or any other single ethnicity. Existing canon and production choices establish a genuinely diverse population.
- Clothing is not a costume. It changes logically with occupation, weather, resources, injury, hygiene, social conditions and time.
- When generating an image, consult the individual entry first, then add the scene/state requested by production.

## Required visual fields
Every human named character must remain trackable through: age, heritage/background where canonically relevant, skin tone/undertone, face structure, eyes, hair, body build, height range, distinguishing marks, personal silhouette, footwear/gear, accessories, occupation identifiers, everyday wardrobe, pre-Collapse wardrobe, early-Collapse adaptation and later-survival evolution. Where relevant, injury/exhaustion/weathering states are cumulative.
